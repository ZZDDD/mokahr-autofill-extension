## 推荐安装：直接下载仓库

1. 打开[项目首页](https://github.com/ZZDDD/mokahr-autofill-extension)。
2. 点击绿色的 `Code`，再点 `Download ZIP`。
3. 解压后，Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
4. 开启开发者模式，点击“加载已解压的扩展程序”。
5. 选择解压得到的 `mokahr-autofill-extension-main` 文件夹。

## 备选：Release 精简包

只想下载运行文件时，请向下滚动到本页面底部，在 `Assets` 区域点击 **`mokahr-autofill-chrome-edge-v0.7.0.zip`**。解压后用相同方式加载，它同时支持 Chrome 和 Edge。

> 两种方式都必须先解压。页面出现 **Mokahr Resume Autofill** 就安装成功了。

## 第一次使用

1. 点击扩展图标，选择“管理资料与附件”。
2. 填写基本信息、教育、实习和项目等资料。
3. 点击“保存简历”。
4. 打开 Mokahr 或飞书招聘申请页。
5. 点击扩展图标，再点击“填充当前页面”。
6. 仔细检查所有字段和未匹配项目，然后由你手动提交。

扩展不会自动提交申请。

## 本版本内容

- 可视化简历管理和 JSON 导入、导出
- 教育、工作、实习、项目等多条经历稳定创建与填写
- 修复 React 延迟更新导致首条经历被末条覆盖的问题
- 修复 10 月至 12 月日期及反向读取后的管理页实时同步
- 支持 Chrome 和 Edge、Mokahr 与飞书招聘域名
- 附带从自然语言或 PDF 生成兼容 JSON 的 Codex Skill

## 升级

建议先在旧版管理页“导出 JSON”备份资料。下载并解压新包后，在扩展管理页点击“重新加载”；如果更换了解压文件夹，请移除旧扩展，再重新“加载已解压的扩展程序”。最后刷新已经打开的招聘申请页。

## 隐私与校验

- 扩展没有服务端、遥测或第三方上传代码。
- 资料保存在浏览器扩展本地存储中，但不是密码加密保险箱，请勿在公用电脑使用。
- `SHA256SUMS.txt` 可用于验证 ZIP 是否完整。在下载文件所在目录运行：

  ```bash
  shasum -a 256 -c SHA256SUMS.txt
  ```
