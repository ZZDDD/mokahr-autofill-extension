## 下载哪个文件？

请在下方 `Assets` 下载：

**`mokahr-autofill-chrome-edge-v0.7.0.zip`**

同一个 ZIP 同时支持 Chrome 和 Edge。不要下载 GitHub 自动生成的 `Source code (zip)` 或 `Source code (tar.gz)`，也不要直接双击 ZIP 安装。

## 小白安装：只需 6 步

1. 下载上面的 ZIP。
2. 右键或双击 ZIP，把它完整解压到一个固定文件夹。
3. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
4. 打开“开发者模式”或“开发人员模式”。
5. 点击“加载已解压的扩展程序”或“加载解压缩的扩展”。
6. 选择解压后能直接看到 `manifest.json` 的文件夹。

页面出现 **Mokahr Resume Autofill** 就安装成功了。建议点击浏览器工具栏的拼图图标，把扩展固定到工具栏。

> 浏览器提示“清单文件缺失”时，说明选错了文件夹。继续进入解压目录，找到 `manifest.json` 所在的那一层再选择。

## 第一次使用

1. 点击扩展图标，选择“管理资料与附件”。
2. 填写基本信息、教育、实习和项目等资料。
3. 点击“保存简历”。
4. 打开 Mokahr 或飞书招聘申请页。
5. 点击扩展图标，再点击“填充当前页面”。
6. 仔细检查所有字段和未匹配项目，然后由你手动提交。

扩展不会自动提交申请。

- 可视化简历管理和 JSON 导入、导出
- 教育、工作、实习、项目等多条经历稳定创建与填写
- 修复 React 延迟更新导致首条经历被末条覆盖的问题

- 支持 Chrome 和 Edge、Mokahr 与飞书招聘域名
- 附带从自然语言或 PDF 生成兼容 JSON 的 Codex Skill

## 升级

建议先在旧版管理页“导出 JSON”备份资料。下载并解压新包后，在扩展管理页点击“重新加载”；如果更换了解压文件夹，请移除旧扩展，再重新“加载已解压的扩展程序”。最后刷新已经打开的招聘申请页。

## 隐私与校验

- 扩展没有服务端、遥测或第三方上传代码。
- 资料保存在浏览器扩展本地存储中，但不是密码加密保险箱，请勿在公用电脑使用。
- `SHA256SUMS.txt` 可用于验证 ZIP 是否完整。在下载文件所在目录运行：

  ```bash
  shasum -a 256 -c SHA256SUMS.txt
  ```
