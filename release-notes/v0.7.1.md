# Mokahr Autofill v0.7.1

> [!WARNING]
> 自动填写可能不准确。提交前请逐项核对姓名、联系方式、证件、学校、公司、经历顺序和日期。

## 本版本修复

- 支持企业自定义招聘域名上的 Mokahr / 飞书简历申请页。
- 已验证 `/resume/.../apply` 形式的自定义域名页面可以被识别和接入。
- 自定义域名仅在用户点击扩展图标后获得当前标签页的临时权限；扩展没有申请 `<all_urls>` 常驻访问权限。
- 非招聘页面及仅有相似 URL、但缺少飞书招聘页面标记的网站不会注入内容脚本。
- 防止弹窗初始化和用户立即操作同时触发时重复注入内容脚本。

## 安装或升级

最简单的方式是从[仓库首页](https://github.com/ZZDDD/mokahr-autofill-extension)点击 `Code`，再点击 `Download ZIP`。解压后，在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 中开启开发者模式并选择“加载已解压的扩展程序”。

只想下载运行文件时，请滚动到本页面底部的 `Assets`，下载 **`mokahr-autofill-chrome-edge-v0.7.1.zip`**。不要下载 GitHub 自动生成的 `Source code`。

从旧版本升级时：

1. 可先在管理页导出 JSON 备份资料。
2. 解压新版本并在扩展管理页点击“重新加载”；若更换了解压目录，则移除旧扩展后重新加载新目录。
3. 刷新已经打开的招聘申请页。
4. 点击扩展图标，确认显示“已识别当前招聘申请页”。

扩展只负责填写，不会自动提交申请。

## 隐私说明

扩展没有服务端、遥测或第三方上传代码。简历资料保存在浏览器扩展本地存储中，但该存储不是密码加密保险箱，请勿在公用电脑使用。

本项目与 Mokahr、飞书、字节跳动及任何招聘网站或招聘公司均无隶属、授权或背书关系。使用者应自行检查填写结果、遵守目标网站条款并对最终提交内容负责。
